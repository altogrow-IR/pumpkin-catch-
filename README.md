# かぼちゃキャッチ大作戦

落ちてくるカボチャをカゴでキャッチする、ハロウィンのミニアクションゲームです。

## 遊び方

- カゴは指・マウス・←→キーで左右に動きます
- 🎃 を取ると +10点、🌟 は +30点
- カボチャを取り逃がすか、👻 を取るとライフが1つ減ります（ライフは3つ）
- 時間がたつほど、落ちるスピードと数が増えていきます
- ハイスコアはこの端末に保存されます

## 開発

```bash
npm ci
npm run dev
```

ビルドは `npm run build`（出力は `dist/`）。GitHub Pages へは、ビルド成果物を `docs/` フォルダに入れておき、リポジトリ設定で Pages の公開元を main ブランチの `/docs` フォルダに指定して公開します。
